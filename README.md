# action-gateway-skill

Agent-readable setup guide for [DigitalOcean Action Gateway](https://cloud.digitalocean.com/managed-agents/action-gateway).

`SKILL.md` is the artifact. A coding agent fetches it, registers the Action
Gateway MCP server, and learns how to discover and invoke catalog tools.

Canonical URL: `https://actions.do-ai.run/skill`

Edit `SKILL.md` through a pull request. The canonical URL serves whatever is on
`main`, so a merge here changes what every agent reads.
